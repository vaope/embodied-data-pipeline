GET STARTED

安装与数据准备

当前发布候选中的检索包可独立安装。需要 Python 3.11+，以及 PATH 中可调用的 FFmpeg 与 ffprobe；现有干净安装验证环境为 Windows / Python 3.13.5。以下命令在仓库根目录执行，输出目录使用新目录。

python -m pip install ./packages/pipeline
edp-retrieve --help
edp-demo --out ./demo-output

合成示例生成三条位姿序列与灰色视频，构建九个窗口并返回两个候选，再读回保存的特征。固定语义向量不涉及语言模型推理。本页真实视频不属于这条合成演示链。

真实语义检索需要安装 semantic 依赖组并准备相应模型、视频和位姿数据；不要把仅有 RGB 的视频当作已有运动轨迹。

python -m pip install "./packages/pipeline[semantic]"

RETRIEVAL LOGIC

两种查询各自怎样检索

Robot → Ego：明确步骤与区间 → 语义召回候选 → 比较末端速度、转动、停顿和路径比例 → 有界调整语义排名 → 返回可复查区间。新版单步示例在语义 Top 50 内重排，缺失运动中性回退；旧放笔示例保留原候选配额与惩罚公式，页面随样例注明差别。

Ego → Ego：文本和起始手型分别排序 → 合并名次召回 → 按查询左右手活动量加权比较位移、转动、指尖和腕部四路运动 → 合并运动名次并限制同源返回数量。使用原始 pose-language-active-v1 路线。

连续步骤：关键步骤多位置召回 → 同源邻域按序对齐 → 记录合并、缺步与映射 → 对已有候选链逐匹配块比较运动 → 输出连续区间。未重新搜索被语义路径舍弃的映射；路径结构完整不等于每一步语义正确。主页样例当前均是单步或固定窗口。
