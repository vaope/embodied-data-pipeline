HOW RETRIEVAL WORKS

检索如何找到这些片段？

离线准备

把候选视频组织为带时间边界的片段，保存描述与可用的手型、运动特征，建立可检索的索引。

查看路线说明 ↗
连续多个步骤时，怎样避免只匹配其中一步？

以关键步骤召回多个可能位置，在同一来源视频的邻域内按顺序匹配查询步骤，记录合并与缺步情况，再对已有候选链按匹配块比较运动，输出连续区间和逐步对应。

连续区间保留中间发生的动作。算法标记“完整”仍需检查每一步语义是否正确；下方当前样例均为单步或固定窗口。

在仓库根目录运行

edp-demo --out ./demo-output

需要 Python 与 FFmpeg/ffprobe。该示例使用合成数据与固定语义向量；本页真实视频是独立的预计算结果。
